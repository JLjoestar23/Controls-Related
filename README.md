# Controls-Related

This repository contains MATLAB experiments for modeling, simulation, animation, and control of classic nonlinear systems.

## Repository structure

- `/MATLAB/simulate_system.m` – main script with simulation setups for:
  - double pendulum
  - single pendulum
  - cart-pole (including LQR + swing-up style control)
- `/MATLAB/systems/` – system dynamics functions.
- `/MATLAB/animations/` – animation utilities for visualizing simulations.
- `/MATLAB/iterative value/` – value-iteration and optimal control experiments.

## Getting started

1. Open MATLAB in the repository root.
2. Run `/MATLAB/simulate_system.m` to simulate and visualize the systems.
3. Explore scripts in `/MATLAB/iterative value/` for value-iteration examples.
